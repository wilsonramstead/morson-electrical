## Build notes
- Single self-contained `index.html`, inline CSS + minimal JS. Works from `file://` and with JS off.
- **Fonts:** Texturina (display, bookish serif) + Cormorant Infant (body, sized up for readability), via Google Fonts.
- **Palette:** midnight-indigo + filament-warm-white + spark-gold.
- `noindex` set (demo) — remove when the client goes live.
- Primary CTA = call; SMS CTA included (solo-operator cell — Brian answers the phone in reviews).
- No contact forms. Footer credit → https://wilsoninnovations.net.

## Facts policy
Only facts from the lead data were used. No invented email, license numbers, founding year, or
"licensed/insured" claims. "Reachable day or night" reflects the Google listing showing Open 24 hours.
Testimonials are paraphrased from real Google reviews (panel/Zinsco replacement, 220V hot tub circuit,
dryer outlet, doorbell, ceiling lights, PG&E/permit coordination).
